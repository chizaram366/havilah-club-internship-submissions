\# Havilah Club Internship — Day 12



\## Python Logic \& Functions



This project contains my Day 12 Python exercises for the Havilah Club Internship.



The project focuses on Python logic, conditional statements, loops, functions, parameters, return values, and basic error handling.



\## Exercises



\### Exercise 1 — Grade Calculator



Created a `calculate\_grade()` function that accepts a score from 0 to 100 and returns a letter grade.



The grading system is:



\* A — 70 to 100

\* B — 60 to 69

\* C — 50 to 59

\* D — 40 to 49

\* F — Below 40



The conditions are arranged from the highest score range to the lowest.



\### Exercise 2 — Multiplication Table



Created a `multiplication\_table()` function that displays the multiplication table for a number from 1 to 12.



A `for` loop is used to repeat the calculation for each multiplier.



The program also uses a `while` loop through the utility menu so the user can perform multiple calculations until choosing Exit.



\### Exercise 3 — Temperature Converter



Created a `celsius\_to\_fahrenheit()` function that receives a Celsius temperature as a parameter and returns the Fahrenheit result.



The conversion formula used is:



```text

Fahrenheit = (Celsius × 9 / 5) + 32

```



\### Exercise 4 — Error Handling



Created a `get\_number()` function using `try` and `except` to handle invalid numerical input.



If the user enters text instead of a number, the program displays an appropriate error message instead of crashing.



\### Exercise 5 — Python Utility Menu



Combined the exercises into an interactive Python utility menu.



The menu provides:



1\. Grade Calculator

2\. Multiplication Table

3\. Temperature Converter

4\. Exit



The menu continues running until the user selects the Exit option.
