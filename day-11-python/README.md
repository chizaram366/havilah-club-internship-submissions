\# Havilah Club Internship — Day 11



\## Introduction to Python



This project contains my Day 11 Python exercises for the Havilah Club Internship.



The project demonstrates fundamental Python concepts including variables, data types, user input, output, type conversion, arithmetic operators, conditional statements, comments, and formatted output.



\## Exercises



\### Exercise 1 — Student Information



Created variables representing student information using four Python data types:



\* String (`str`)

\* Integer (`int`)

\* Float (`float`)

\* Boolean (`bool`)



The program displays each value and its corresponding data type using `type()`.



\### Exercise 2 — Basic Calculator



The program asks the user to enter two numbers and calculates:



\* Sum

\* Difference

\* Product

\* Quotient

\* Remainder



The numerical inputs are converted using `float()` before performing calculations.



\### Exercise 3 — Temperature Converter



The program accepts decimal temperature values and performs two conversions:



\* Celsius to Fahrenheit

\* Fahrenheit to Kelvin



\### Exercise 4 — Robot Sensor Monitor



The program collects:



\* Robot Name

\* Robot ID

\* Sensor Name

\* Sensor Reading

\* Operating Limit



The sensor reading and operating limit are converted to numerical values. The program then calculates the difference between the operating limit and the current sensor reading and displays a formatted sensor report.
